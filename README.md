# Velox Play para Android TV

APK de teste da versão **1.0.7** para instalação manual em Android TV.

## Instalar com Downloader

1. No Downloader da TV, abra este link direto:

   `https://github.com/aprovaestaaqui-byte/velox-play-android-tv/releases/download/v1.0.7/Velox-Play-Android-TV-v1.0.7.apk`

2. Se a TV solicitar, permita a instalação de apps desta fonte e instale o APK.

O APK é uma compilação de **teste (debug)**, assinada para instalação manual. Não é uma versão de produção ou de loja. O arquivo `SHA256.txt` permite conferir a integridade do download.

O conteúdo do aplicativo depende da lista configurada pelo próprio usuário e de conexão de rede. Este repositório de distribuição contém somente o instalador e instruções; não inclui credenciais ou listas.
